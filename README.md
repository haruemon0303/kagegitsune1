# 影狐（かげぎつね）- Sound Novel Web App

スマートフォン対応のサウンドノベル（アドベンチャーゲーム）Webアプリケーションです。文章中心の物語が進行し、選択肢によって分岐します。BGM、効果音、静止画（背景・シルエット）の演出を重視した作りになっています。

## 特徴

- **完全スタンドアロン**: HTML/CSS/JavaScriptのみで構築、外部ライブラリ・CDN不要
- **スマホ最適化**: レスポンシブデザインでスマートフォンに最適化
- **GitHub Pages対応**: 外部サーバ不要で公開可能
- **豊富な演出**: フラッシュ、画面揺れ、ノイズなどの視覚効果
- **音声対応**: BGMループ再生、効果音、iOS自動再生制限に対応
- **セーブ/ロード**: localStorageで進行状況を保存
- **バックログ**: テキストログで過去のテキストを確認可能
- **オート再生**: 自動でテキストを進行
- **スキップ機能**: 既読シーンを高速スキップ

## GitHub Pagesでの公開方法

### 1. リポジトリの準備

このリポジトリをGitHubにプッシュします（既に完了している場合はスキップ）。

```bash
git add .
git commit -m "Add sound novel web app"
git push origin main
```

### 2. GitHub Pagesの有効化

1. GitHubのリポジトリページにアクセス
2. **Settings** タブをクリック
3. 左サイドバーの **Pages** をクリック
4. **Source** セクションで以下を設定：
   - **Branch**: `main`（またはあなたのデフォルトブランチ）
   - **Folder**: `/ (root)`
5. **Save** をクリック

数分後、`https://[ユーザー名].github.io/[リポジトリ名]/` でアクセス可能になります。

### 3. カスタムドメインの設定（オプション）

独自ドメインを使用する場合は、GitHub Pages設定の **Custom domain** で設定できます。

## 使い方

### 基本操作

1. **ゲーム開始**: 初回画面をタップしてゲームを開始
2. **テキスト進行**: テキストエリアをタップまたはクリックで次のテキストへ
3. **選択肢**: 選択肢が表示されたら、ボタンをタップして選択
4. **メニュー**: 右上の「☰」ボタンでメニューを開く
5. **設定**: 右上の「⚙」ボタンで音量調整・ミュート設定

### メニュー機能

- **セーブ**: 現在の進行状況を保存（ブラウザのlocalStorageに保存）
- **ロード**: 保存した進行状況から再開
- **最初から**: ゲームを最初から開始

### テキストボックスの機能

- **ログ**: 過去のテキストを確認（バックログ）
- **オート**: 自動でテキストを進行（オン/オフ切り替え）
- **スキップ**: 既読シーンを高速スキップ（オン/オフ切り替え）

### 設定項目

- **BGM音量**: BGMの音量を調整（0-100）
- **SE音量**: 効果音の音量を調整（0-100）
- **BGMミュート**: BGMをミュート
- **SEミュート**: 効果音をミュート

## カスタマイズ方法

### 物語の編集（story.json）

`story.json`を編集することで、物語をカスタマイズできます。

#### 基本構造

```json
{
  "title": "ゲームタイトル",
  "startScene": "opening",
  "backgrounds": { ... },
  "silhouettes": { ... },
  "bgm": { ... },
  "se": { ... },
  "scenes": { ... }
}
```

#### シーンの定義

```json
"scene_id": {
  "background": "背景ID",
  "silhouette": "シルエットID（オプション）",
  "bgm": "BGM ID（オプション）",
  "text": [
    {
      "type": "narration",  // narration, dialogue, system
      "text": "表示するテキスト",
      "se": "効果音ID（オプション）",
      "effect": "演出効果（オプション）"  // flash, shake, noise
    }
  ],
  "next": "次のシーンID（オプション）",
  "choices": [  // 選択肢（オプション）
    {
      "label": "選択肢のテキスト",
      "nextScene": "次のシーンID"
    }
  ]
}
```

#### テキストタイプ

- **narration**: 地の文（通常のテキスト）
- **dialogue**: 会話（斜体で表示、左に線が表示される）
- **system**: システムメッセージ（オレンジ色で表示）

#### 演出効果

- **flash**: 画面フラッシュ（白い光が一瞬光る）
- **shake**: 画面揺れ（画面が揺れる）
- **noise**: ノイズ効果（画面にノイズが走る）

### 背景・シルエット画像の追加

1. `assets/images/`に画像ファイルを配置
2. `story.json`の`backgrounds`または`silhouettes`に追加：

```json
"backgrounds": {
  "my_background": "assets/images/my_bg.png"
}
```

### BGM・効果音の追加

1. `assets/bgm/`または`assets/se/`に音声ファイルを配置
2. `story.json`の`bgm`または`se`に追加：

```json
"bgm": {
  "my_music": "assets/bgm/my_music.wav"
}
```

**対応フォーマット**: WAV, MP3, OGG（ブラウザによる）

## トラブルシューティング

### 音が鳴らない

- iOS/Safariの場合、初回タップ後に音声が有効化されます
- 設定でミュートになっていないか確認してください
- ブラウザの音量設定を確認してください

### セーブデータが消える

- ブラウザのキャッシュをクリアするとlocalStorageのデータも消えます
- プライベートブラウジングモードではlocalStorageが使用できません

### 画像が表示されない

- ファイルパスが正しいか確認してください
- 画像ファイルが`assets/images/`に配置されているか確認してください
- ブラウザの開発者ツールでエラーを確認してください
