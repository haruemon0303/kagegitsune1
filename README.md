# かげぎつねの山 - Sound Novel Web App

スマートフォン対応のサウンドノベル（アドベンチャーゲーム）Webアプリケーションです。吹雪の山荘を舞台にした本格ミステリー物語が展開されます。文章中心で進行し、選択肢によって分岐します。BGM、効果音、静止画（背景・シルエット）の演出を重視した作りになっています。

## ストーリー

雪山の氷室館に集まった8人の宿泊客。閉ざされた館で起きる連続殺人事件。カゲギツネの伝説と、ダイイングメッセージに隠された真実とは――？

主人公とその友人・山岡拓也が、真相を暴くために事件の謎に挑む本格推理サウンドノベルです。

## 特徴

- **完全スタンドアロン**: HTML/CSS/JavaScriptのみで構築、外部ライブラリ・CDN不要
- **スマホ最適化**: レスポンシブデザインでスマートフォンに最適化
- **GitHub Pages対応**: 外部サーバ不要で公開可能
- **現在はサウンド無効化中**: BGM/SEは再生されません
- **主人公名カスタマイズ**: プレイヤーが主人公の名前を設定可能（8文字以内）
- **豊富な演出**: フラッシュ、画面揺れ、ノイズなどの視覚効果
- **音声対応**: BGMループ再生、効果音、iOS自動再生制限に対応
- **セーブ/ロード**: localStorageで進行状況を保存
- **バックログ**: テキストログで過去のテキストを確認可能
- **オート再生**: 自動でテキストを進行
- **スキップ機能**: 既読シーンを高速スキップ
- **分岐ストーリー**: 選択肢によって物語が変化

## 現在の実装範囲（MVP版）

現在、以下の範囲まで実装・プレイ可能です：

### 実装済みシーン
- **プロローグ**: 吹雪の峠道（シーン1）
- **第一章**: 氷室館の夜
  - シーン2: 到着
  - シーン3: 夕食・宿泊者たちの顔ぶれ
- **第二章**: 最初の犠牲者
  - シーン4: 発見
  - シーン5: 選択（3択分岐）
- **分岐A（協力ルート）**:
  - シーン6: 捜査開始
  - シーン7: 現場検証 → 選択肢（3択）
    - A-1: 廊下を確認 → NORMAL END
    - A-2: 挟み撃ち → Chapter 3へ
    - A-3: 気づかないふり → TRUE END
- **分岐B（拒否ルート）**: BAD END
- **分岐C（単独調査ルート）**: BAD END
- **第三章**: 深まる謎
  - シーン8: 深夜の告白 → 3択分岐
    - 美雪を疑う → 分岐B（美雪ルート）
    - その他 → NORMAL END

### 到達可能なエンディング（現在11種類）

#### TRUE END（真エンド）
- **TRUE END「復讐の代償」**: 分岐A-3（気づかないふり）から到達。地下室で真実を知り、警察に証言する。

#### SECRET END（隠しエンド）
- **SECRET END「かげぎつねの正体」**: 特定の5つの条件をすべて満たしてエンディングに到達すると、通常のENDの代わりに自動的に遷移します。真の黒幕・神崎玲子の正体が明らかになります。

**SECRET END到達条件（以下の5つをすべて満たす必要があります）**:
1. **協力フラグ**: Chapter 2 Scene 5で「もちろんだ、一緒に調べよう」を選択（山岡と協力する）
2. **挟み撃ちフラグ**: Route A Scene 7で「挟み撃ち」を選択（A-2ルートへ進む）
3. **慎重判断フラグ**: Route A-2で「まだ判断できない、もっと情報が必要だ」を選択（早まった判断をしない）
4. **美雪疑惑フラグ**: Chapter 3 Scene 8で「あなた、何か隠していませんか？」を選択（美雪を疑う）
5. **代替エンド回避フラグ**: Chapter 3 Scene 9 Alternative（語られない真実）に到達しない

※デバッグモードをONにすると、画面右上に各フラグの状態が表示されます（✓=達成、✗=未達成）

#### NORMAL END（通常エンド）
- **NORMAL END「雪に埋もれた真実」**: 分岐A-1（廊下を確認）から到達。手がかりを掴むも真相に辿り着けず。
- **NORMAL END「償いの涙」**: 分岐B-2-1（山岡に報告）から到達。美雪の復讐が明らかになり逮捕される。
- **NORMAL END「語られない真実」**: Chapter 3（深夜の告白）で追求しなかった場合。美雪の秘密は封印される。

#### BAD END（バッドエンド）
- **BAD END 1「無力な傍観者」**: 分岐B-2-2（盗み聞き続行）から到達。バレて監禁される。
- **BAD END 2「遅すぎた決断」**: 分岐B-3（様子見）から到達。山岡が殺される。
- **BAD END「協力の拒否」**: 分岐B（拒否ルート）から到達。山岡の調査を拒否し、事件は未解決に。
- **BAD END「孤独な探偵」**: 分岐C（単独調査）から到達。単独行動で襲われる。
- **BAD END「情報収集の果て」**: 分岐B（聞き込み）から到達。情報収集に時間をかけすぎて事態が悪化。

### デバッグ機能

**デバッグモード**: 設定画面からON/OFFできるデバッグ表示機能を追加しました。
- ONにすると画面右上に現在のシーンIDとフラグ状態が表示されます
- 例: `DEBUG: scene=route_a_scene7 | coop:✓ pinch:✗ info:✗ suspect:✗ noAlt:✓`
- フラグ状態を確認してSECRET ENDの条件達成状況を確認できます
- 分岐で行き詰まった際の報告にも便利です

## GitHub Pagesでの公開方法

### 1. リポジトリの準備

このリポジトリをGitHubにプッシュします（既に完了している場合はスキップ）。

```bash
git add .
git commit -m "Add sound novel web app"
git push origin main
```

### 2. GitHub Pagesの有効化

1. GitHubのリポジトリページにアクセス
2. **Settings** タブをクリック
3. 左サイドバーの **Pages** をクリック
4. **Source** セクションで以下を設定：
   - **Branch**: `main`（またはあなたのデフォルトブランチ）
   - **Folder**: `/ (root)`
5. **Save** をクリック

数分後、`https://[ユーザー名].github.io/[リポジトリ名]/` でアクセス可能になります。

### story.json をPages上で確認する手順

1. ブラウザで `https://[ユーザー名].github.io/[リポジトリ名]/story.json` を開く
2. JSONが表示されれば、Pages上の`story.json`が反映済みです
3. 変更後に反映されない場合は、ブラウザのキャッシュを更新してください

### 3. カスタムドメインの設定（オプション）

独自ドメインを使用する場合は、GitHub Pages設定の **Custom domain** で設定できます。

## 使い方

### 基本操作

1. **ゲーム開始**: 初回画面をタップ
2. **主人公名入力**: 名前を入力（8文字以内、初期値「主人公」）
3. **テキスト進行**: テキストエリアをタップまたはクリックで次のテキストへ
4. **選択肢**: 選択肢が表示されたら、ボタンをタップして選択
5. **メニュー**: 右上の「☰」ボタンでメニューを開く
6. **設定**: 右上の「⚙」ボタンで音量調整・ミュート設定

### 主人公名について

- **初回起動時**: ゲーム開始直後に名前入力画面が表示されます
- **保存**: 入力した名前はlocalStorageに保存され、次回起動時も使用されます
- **変更方法**: メニューから「名前変更」を選択することで、いつでも変更可能
- **本文での反映**: ストーリー中の「主人公名」が、設定した名前に自動置換されます
- **制限**: 8文字以内、空白不可

### メニュー機能

- **セーブ**: 現在の進行状況を保存（ブラウザのlocalStorageに保存）
- **ロード**: 保存した進行状況から再開
- **名前変更**: 主人公の名前を変更（新機能）
- **最初から**: ゲームを最初から開始

### テキストボックスの機能

- **ログ**: 過去のテキストを確認（バックログ）
- **オート**: 自動でテキストを進行（オン/オフ切り替え）
- **スキップ**: 既読シーンを高速スキップ（オン/オフ切り替え）

### 設定項目

- **BGM音量**: BGMの音量を調整（0-100）
- **SE音量**: 効果音の音量を調整（0-100）
- **BGMミュート**: BGMをミュート
- **SEミュート**: 効果音をミュート
- **デバッグモード**: 現在のシーンIDを画面右上に表示（デフォルトOFF）

## カスタマイズ方法

### 物語の編集（story.json）

`story.json`を編集することで、物語をカスタマイズできます。

#### 基本構造

```json
{
  "title": "ゲームタイトル",
  "startScene": "opening",
  "backgrounds": { ... },
  "silhouettes": { ... },
  "bgm": { ... },
  "se": { ... },
  "scenes": { ... }
}
```

#### シーンの定義

```json
"scene_id": {
  "background": "背景ID",
  "silhouette": "シルエットID（オプション）",
  "bgm": "BGM ID（オプション）",
  "text": [
    {
      "type": "narration",  // narration, dialogue, system
      "text": "表示するテキスト",
      "se": "効果音ID（オプション）",
      "effect": "演出効果（オプション）"  // flash, shake, noise
    }
  ],
  "next": "次のシーンID（オプション）",
  "choices": [  // 選択肢（オプション）
    {
      "label": "選択肢のテキスト",
      "nextScene": "次のシーンID"
    }
  ]
}
```

#### テキストタイプ

- **narration**: 地の文（通常のテキスト）
- **dialogue**: 会話（斜体で表示、左に線が表示される）
- **system**: システムメッセージ（オレンジ色で表示）

#### 演出効果

- **flash**: 画面フラッシュ（白い光が一瞬光る）
- **shake**: 画面揺れ（画面が揺れる）
- **noise**: ノイズ効果（画面にノイズが走る）

#### 主人公名の置換

テキスト内に「主人公名」と記載すると、プレイヤーが設定した名前に自動置換されます。

```json
{
  "type": "narration",
  "text": "私の名前は主人公名という。"
}
```

### 背景・シルエット画像の追加

1. `assets/images/`に画像ファイルを配置
2. `story.json`の`backgrounds`または`silhouettes`に追加：

```json
"backgrounds": {
  "my_background": "assets/images/my_bg.png"
}
```

### BGM・効果音の追加

1. `assets/bgm/`または`assets/se/`に音声ファイルを配置
2. `story.json`の`bgm`または`se`に追加：

```json
"bgm": {
  "my_music": "assets/bgm/my_music.wav"
}
```

**対応フォーマット**: WAV, MP3, OGG（ブラウザによる）

## トラブルシューティング

### 音が鳴らない

- iOS/Safariの場合、初回タップ後に音声が有効化されます
- 設定でミュートになっていないか確認してください
- ブラウザの音量設定を確認してください

### セーブデータが消える

- ブラウザのキャッシュをクリアするとlocalStorageのデータも消えます
- プライベートブラウジングモードではlocalStorageが使用できません

### 画像が表示されない

- ファイルパスが正しいか確認してください
- 画像ファイルが`assets/images/`に配置されているか確認してください
- ブラウザの開発者ツールでエラーを確認してください

### 主人公名が置換されない

- `story.json`内で「主人公名」というテキストを使用しているか確認
- 名前入力画面で正しく名前を入力したか確認
- ブラウザのlocalStorageがクリアされていないか確認
